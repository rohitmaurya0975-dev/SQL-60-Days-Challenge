## 🧠 Skills Practiced

### SQL Querying
```sql
SELECT *
FROM employee2;
```

### Filtering
```sql
SELECT *
FROM employee2
WHERE salary > 50000;
```

### Sorting
```sql
SELECT *
FROM employee2
ORDER BY salary DESC;
```

### Multiple Conditions
```sql
SELECT *
FROM employee2
WHERE city = 'Delhi'
AND department = 'Sales';
```

### Unique Values
```sql
SELECT DISTINCT department
FROM employee2;
```

# 🐛 Debugging Practice

I also practice identifying and correcting SQL errors.

### My debugging approach:

1. Understand the error
2. Check table name
3. Check column names
4. Check SQL syntax
5. Check conditions
6. Run the query again
7. Verify the output
8. Save the corrected query
